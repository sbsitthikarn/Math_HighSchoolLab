    สรุปหลักสำคัญจากบทเรียน Graphs of Quadratic Functions ใช้ทบทวนก่อนลงมือฝึก

    Standard form

    y = ax2 + bx + c, a ≠ 0

    • a > 0 เปิดขึ้น มีจุดต่ำสุด (minimum point) · a < 0 เปิดลง มีจุดสูงสุด (maximum point)
    • ยิ่ง a ใกล้ 0 กราฟยิ่งบานกว้าง
    • ตัดแกน y ที่จุดเดียวคือ (0, c)
    • แกนสมมาตร (line of symmetry) x = −b ÷ 2a ผ่านจุดวกกลับ (turning point)
    Completed-square form

    y = a(x − h)2 + k

    • จุดวกกลับคือ (h, k) และแกนสมมาตรคือ x = h
    • ระวังเครื่องหมาย: (x + 3)2 หมายถึง h = −3
    • ทำกำลังสองสมบูรณ์ (completing the square): x2 + bx = (x + b/2)2 − (b/2)2
    Factorised form

    y = ±(x − p)(x − q)

    • ตัดแกน x ที่ x = p และ x = q
    • แกนสมมาตรอยู่กึ่งกลาง x = (p + q) ÷ 2
    • ระยะตัดแกน y คือ pq (หรือ −pq เมื่อหน้าวงเล็บเป็นลบ)
    Graphical method

    แก้สมการกำลังสองด้วยกราฟ

    • รากของ ax2 + bx + c = 0 คือพิกัด x ที่กราฟตัดแกน x
    • ตัด 2 จุด → 2 รากต่างกัน · แตะ 1 จุด → รากซ้ำ (repeated roots) · ไม่ตัด → ไม่มีรากจริง (no real roots)
    • แก้ f(x) = k ให้วาดเส้น y = k แล้วอ่านพิกัด x ของจุดตัด
    • แก้ f(x) = mx + d ให้วาดเส้นตรง y = mx + d บนแกนเดียวกัน
    • จัดสมการให้ด้านหนึ่งเหมือนกราฟที่มีอยู่ อีกด้านคือเส้นที่ต้องวาด
    Applications

    โจทย์ประยุกต์

    • ค่าสูงสุดหรือต่ำสุดของปริมาณ = พิกัด y ของจุดวกกลับ เกิดขึ้นเมื่อ x (หรือ t) เท่ากับพิกัด x ของจุดวกกลับ
    • ค่าเมื่อ t = 0 คือค่าเริ่มต้น เช่น ความสูงของอาคาร
    • เมื่อวัตถุตกถึงพื้น h = 0 เลือกเฉพาะคำตอบที่สมเหตุสมผล (t ≥ 0)
    • ใช้ความสมมาตร: จุดที่มีความสูงเท่ากันอยู่ห่างแกนสมมาตรเท่ากัน
